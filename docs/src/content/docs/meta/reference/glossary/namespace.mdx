<p>{frontmatter.definition}</p>

manni graph's own namespace is `graph:`, which resolves to
`https://hawkeyexl.github.io/manni/graph/ns#`. The document at that address
defines every term the emitter can produce. The namespace stays small on
purpose. A Dublin Core, SKOS, PROV, schema.org, FOAF or iiRDS term is preferred
wherever one exists.

The `graph:` prefix shares its spelling with the page's
[`graph` block](/manni/meta/reference/glossary/graph-block/) but names a different thing. The block is
frontmatter, and the prefix abbreviates an IRI.
