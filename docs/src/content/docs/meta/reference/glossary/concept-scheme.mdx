<p>{frontmatter.definition}</p>

A label on a page resolves to a term by its label, its id, then an
alt-label. So each spelling of a term meets on one node. A label no term
defines stays a freeform concept. See
[One concept scheme](/manni/graph/get-started/how-graph-works/#one-concept-scheme).
