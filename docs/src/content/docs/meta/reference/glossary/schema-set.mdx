<p>{frontmatter.definition}</p>

manni meta resolves a schema **set** per file, then validates the file's
metadata against **every** [schema](/manni/meta/reference/glossary/schema/) in
it. A file passes only when it satisfies all schemas in its set, and each
reported error is tagged with the schema that produced it. See
[Schema resolution](/manni/meta/reference/schema-resolution/#validating-against-the-whole-set).
