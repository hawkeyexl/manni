<p>{frontmatter.definition}</p>

It decides whether the graph's node names stay local or become web
addresses that a linked-data client can open.

It defaults to `urn:manni:graph:`, which identifies a node without promising
to resolve it. Set it to an HTTP base when you publish the graph and its nodes
should dereference. The [configuration reference](/manni/graph/reference/configuration/)
lists the key.
