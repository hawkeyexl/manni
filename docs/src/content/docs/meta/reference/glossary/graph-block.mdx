<p>{frontmatter.definition}</p>

The page vocabulary `manni:graph:1.0.0` defines it, and a JSON Pointer into
it starts `/graph/`, as in `/graph/label`. The block is closed, so a
misspelled key inside it fails validation. The RDF prefix `graph:` is spelled
the same way and is a different thing. See [namespace](/manni/meta/reference/glossary/namespace/).
