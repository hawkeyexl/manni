<p>{frontmatter.definition}</p>

Its `under` names a term, and limits the values to the terms below it, at any
depth. `manni meta validate` reports a value that names no term, one outside
the branch, and one written as an alt-label. See
[Term values](/manni/meta/schemas/term-values/).
