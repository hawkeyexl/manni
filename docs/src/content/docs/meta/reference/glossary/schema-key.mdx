{/* cite schema-key-stripped-before-validation */}
It takes a single reference or a list. Because it's a manni meta directive
rather than real metadata, `$schema` is **stripped before validation**, so a
schema with `additionalProperties: false` won't flag it. In the
[precedence chain](/manni/meta/reference/glossary/override/) it sits above
config but below a `--schema` flag. A schema carries a different value under the
same key, its [meta-schema URI](/manni/meta/reference/glossary/meta-schema-uri/).
See
[The `$schema` key in a file](/manni/meta/reference/schema-resolution/#the-schema-key-in-a-file).
