<p>{frontmatter.definition}</p>

In manni meta, "override" has two related senses:

- A config **`overrides`** entry assigns a
  [schema set](/manni/meta/reference/glossary/schema-set/) to files matching a
  glob, so different folders can use different schemas. See
  [Apply different schemas to different folders](/manni/meta/set-up/different-schemas-per-folder/).
- More broadly, schema resolution is a chain of overrides. A `--schema` flag
  overrides a document's [`$schema`](/manni/meta/reference/glossary/schema-key/).
  That overrides config `overrides`, which override config `schemas`. The
  first source that yields a schema wins. Config `schemas` join the built-in
  default set rather than override it, and so does an override that sets
  `defaults: true`.
  See [Precedence](/manni/meta/reference/schema-resolution/#precedence).
