<p>{frontmatter.definition}</p>

It saves spelling out a full IRI every time a query or a traversal names a
term.

`dcterms:subject` is the CURIE for `http://purl.org/dc/terms/subject`.
`graph query` and `graph traverse` accept one anywhere they accept a term.
