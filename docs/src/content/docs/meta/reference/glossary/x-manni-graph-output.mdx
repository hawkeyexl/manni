<p>{frontmatter.definition}</p>

It keeps a field that names people out of everything the graph exports,
while the page itself still carries it.

Absent means `true`. `manni:stewardship:1.1.0` marks `owner`,
`stakeholders` and `reviewed-by` as `false`, because those three name people.
The filter runs once, before [derivation](/manni/meta/reference/glossary/derivation/), so a dropped
field is absent from every export.
