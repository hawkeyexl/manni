{/* cite one-extractor-per-format */}
{/* cite stdin-requires-as */}
manni meta has one extractor per input format: Markdown, MDX, AsciiDoc,
reStructuredText, XML, and HTML. The extractor is the only part of manni meta
that knows about a file's format. Once it produces
[metadata](/manni/meta/reference/glossary/metadata/), validation and reporting
work the same for every format. You can force a specific extractor with `--as`,
which is required when reading from stdin. See
[Supported formats](/manni/meta/reference/formats/).
