<p>{frontmatter.definition}</p>

manni meta validates a file's metadata against one or more schemas. A schema
can be shipped with manni meta (a
[builtin](/manni/meta/reference/glossary/schema-reference/)), a local file, or a
remote URL. The JSON Schema specification is at
[json-schema.org](https://json-schema.org/).
