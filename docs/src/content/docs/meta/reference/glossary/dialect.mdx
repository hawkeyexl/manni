<p>{frontmatter.definition}</p>

manni meta auto-detects a schema's dialect from its
[meta-schema URI](/manni/meta/reference/glossary/meta-schema-uri/), and compiles
it with the matching validator. A missing or unrecognized URI falls back to
Draft 2020-12. Schemas of different dialects can coexist in one run. See
[Dialects](/manni/meta/reference/schema-resolution/#dialects).
