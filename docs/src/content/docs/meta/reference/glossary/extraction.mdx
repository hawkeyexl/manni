{/* cite get-validates-nothing */}
The `get` command prints named field values and validates nothing. Extraction
and [validation](/manni/meta/reference/glossary/validation/) are two distinct
operations, exposed as two commands. Every validation begins with an
extraction, but you can extract without validating. See the
[CLI reference](/manni/meta/reference/cli/).
