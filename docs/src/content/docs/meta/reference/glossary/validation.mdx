That is the `validate` command, the one CI gates on. Validation and
[extraction](/manni/meta/reference/glossary/extraction/) are two distinct
operations, exposed as two commands. Every validation begins with an
extraction, but you can extract without validating. See the
[CLI reference](/manni/meta/reference/cli/).
