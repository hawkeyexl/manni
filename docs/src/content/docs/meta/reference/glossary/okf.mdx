<p>{frontmatter.definition}</p>

The schema's id is `google:okf:0.1`. OKF requires only `type` and treats every
other field (`title`, `description`, `resource`, `tags`, `timestamp`) as
recommended, tolerating unknown keys. It's what validates your files when
nothing else is configured. See
[the built-in OKF schema](/manni/meta/reference/okf-schema/).
