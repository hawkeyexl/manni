<p>{frontmatter.definition}</p>

It lets you decide how sure a model must be before `graph fill` writes its
value into a page.

`fill.confidenceThreshold` is the bar a proposal must clear to be written.
Raw proposals are cached before the bar applies, so changing it costs nothing.
