<p>{frontmatter.definition}</p>

Some facts can be stated inside the [`graph` block](/manni/meta/reference/glossary/graph-block/) and
also as a plain page-level key. A `graph` block that speaks to a fact owns it
outright. Where the block is silent, the page-level twin feeds the graph. The
rule applies per fact rather than per page.
