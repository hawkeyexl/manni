The terms below are defined as manni meta uses them. Where a concept has a fuller
reference page, the entry links to it.

| Term | In short |
|---|---|
| [frontmatter](/manni/meta/reference/glossary/frontmatter/) | The metadata block at the very top of a document. |
| [metadata](/manni/meta/reference/glossary/metadata/) | The key/value pairs manni meta validates. |
| [extractor](/manni/meta/reference/glossary/extractor/) | The format-specific reader of a document's metadata. |
| [schema](/manni/meta/reference/glossary/schema/) | A JSON Schema declaring the metadata a file carries. |
| [schema set](/manni/meta/reference/glossary/schema-set/) | The schemas resolved for one file, all of which apply. |
| [schema reference](/manni/meta/reference/glossary/schema-reference/) | A pointer to a schema, as a builtin id, file, or URL. |
| [`$schema` key](/manni/meta/reference/glossary/schema-key/) | The key a document uses to name its own schemas. |
| [meta-schema URI](/manni/meta/reference/glossary/meta-schema-uri/) | The URI that declares the dialect a schema is written in. |
| [dialect](/manni/meta/reference/glossary/dialect/) | A version of the JSON Schema specification. |
| [JSON Pointer](/manni/meta/reference/glossary/json-pointer/) | The syntax that names the field an error is about. |
| [OKF](/manni/meta/reference/glossary/okf/) | The format of the schema anchoring manni meta's default set. |
| [override](/manni/meta/reference/glossary/override/) | A source that outranks another in schema resolution. |
| [validation](/manni/meta/reference/glossary/validation/) | Checking extracted metadata against its schema set. |
| [extraction](/manni/meta/reference/glossary/extraction/) | Reading metadata out of a document. |
