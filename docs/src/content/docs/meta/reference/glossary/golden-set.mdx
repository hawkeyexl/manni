<p>{frontmatter.definition}</p>

It is every page's `sample-questions` plus the golden-set files that
`graph.questionFiles` names. `graph fill` drafts questions marked
`reviewed: false`, and only reviewed ones count toward
`foundThreshold`. See
[Keep a golden set of reader questions](/manni/graph/questions/).
