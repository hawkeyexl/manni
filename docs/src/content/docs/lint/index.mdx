<Aside type="note" title="In development">
`manni lint` is in development. It is not in the published package.
</Aside>

`manni meta` checks what a page says it is. `manni lint` checks whether it is shaped like one. A page that declares `type: how-to` carries an overview, the prerequisites, the steps and somewhere to go next.
