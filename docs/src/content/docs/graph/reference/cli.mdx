Ten commands under one domain. Every flag below is verified against
`src/graph/cli.ts`, and the exit codes are exercised by the inline tests at the
foot of this page.

```sh
manni graph <command> [command options] [arguments]
```

There is no default subcommand. `manni graph docs/` is a usage error, because a
domain owns verbs and `build` is the verb.

## Common conventions

Two verbs read **documents**: `build` and `fill`. They take positional paths,
which are files, directories, or globs relative to the working directory. With
none given they read every
[collection](/manni/meta/reference/configuration/#collections) the config
declares, or the ones `--collection` names. A collection's `paths` resolve from
the config file's directory, wherever the command runs. A document's
`graph:path` and node IRI count from the working directory for a typed path, and
from the config file's directory for a collection. Nothing matching is
**exit 2**, not an empty successful build, unless `--allow-empty` is given.

`-` reads one more document from stdin, alongside any named paths and never
instead of them. It needs `--as`, because stdin has no file name to choose a
parser by. Its display path is `<stdin>`, its node is `<baseIri>stdin`, and its
relative links resolve from the working directory. It has no git history.
It belongs to no collection, so no external-metadata manifest supplies its fields.

The other verbs read the **built graph** rather than the documents: `check`,
`query`, `stats`, `search`, `traverse`, `embed` and `export` all load the
Turtle file at `graph.out`, or the one `-g` names. Build first, then ask.

| Flag | Commands | Meaning |
|---|---|---|
| `-c, --config <path>` | all except `init` | Path to `manni.config.yaml`. Without it, manni graph looks for that file from the working directory up to the repository root. It reads the file's `graph:` key plus the top-level `collections:` and `providers:` keys. With no file at all, built-in defaults apply and no collections are declared. |
| `--no-config` | same as above | Ignore any discovered config file and run on built-in defaults. It shares one option with `-c`, so the one written later wins. |
| `--collection <name>` | `build`, `fill` | Read only this configured collection. Repeatable, one name per occurrence, never comma-separated. It cannot be combined with positional paths, and it needs a config file to select from. Each of those is **exit 2**. |
| `--exclude <glob>` | same as above | Glob to exclude. Repeatable, one glob per occurrence. |
| `--as <format>` | same as above | Parse every input as `asciidoc`, `html`, `markdown`, `mdx`, `rst` or `xml`, whatever its extension. Required with `-`. Another value is **exit 2**. |
| `--ext <list>` | same as above | Extensions a directory walk or a glob keeps, comma-separated and given once. A file named outright is kept whatever this says, when a parser reads its extension. A named file none reads is skipped with a warning. |
| `--allow-empty` | same as above | Treat zero matched files as success. |
| `-g, --graph <path>` | the graph readers | The built Turtle file. Defaults to the resolved `graph.out`. |
| `-f, --format <format>` | every verb that reports | `pretty` or `json`; `check` adds `github`. An unknown value is refused while the options are parsed. A typo therefore costs a message rather than a graph load: **exit 2**, with the allowed set named. |

Flags override config; they do not bypass it. An unset flag falls through to
the resolved `graph:` value, so a config file and the command line reach the same
code.

One separator per list. A positional variadic is space-separated because argv
is. `--ext`, `--fields` and `--predicates` are written `<list>`, comma-separated
and given once. `--collection`, `--exclude` and `--shapes` are repeatable and never
split on commas, because a path or a name may hold one.

Each command's table below lists every flag it accepts, the shared ones
included. A table is the whole surface of its command.

## Global options

Global options are accepted before the subcommand.

| Option | Description |
|---|---|
| `-V, --version` | Print the manni version and exit. |
| `-h, --help` | Print help for the program or a subcommand. |

## `graph`

The knowledge-graph tool. Every command on this page lives under it. `graph`
accepts its own `-V, --version`, which reports the manni version, and
`-h, --help`.

```sh
manni graph <command> [command options] [arguments]
```

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `--no-color` | n/a | color on a TTY | Turn colored output off. `NO_COLOR` in the environment does the same, and output that is not a terminal is never colored either way. |

## `graph init`

Writes a starter `graph:` section into `manni.config.yaml` in the working
directory, and prints the path it wrote. Takes no arguments and no options.

```sh
manni graph init
```

## `graph build`

Reads the documents, derives the graph, and writes canonically sorted Turtle.
Two runs over unchanged inputs are byte-identical. Dates come from
frontmatter and then from git committer times, never from the clock. Every
node gets a deterministic IRI rather than a blank node.

A page's frontmatter is its metadata as `manni meta validate` reads it. A field
kept in a collection's
[external-metadata manifest](/manni/meta/set-up/external-metadata/) derives
exactly as one written on the page.

```sh
manni graph build [paths...] [options]
```

```console
$ manni graph build -c test/graph/fixtures/dd/docs.config.yaml
Wrote .tmp/dd/graph.ttl (3 docs, 157 triples)
```

A page piped in with `-` joins the graph beside the named paths:

```console
$ cat draft.md | manni graph build - docs/ --as markdown
Wrote graph/graph.ttl (4 docs, 152 triples)
```

Warnings go to stderr, so stdout stays the one-line summary. A degraded build
is still a successful one. A repository git cannot read warns once and builds
the rest. A near-miss frontmatter key warns and derives nothing. Neither
changes the exit code.

### Arguments

| Argument | Description |
|---|---|
| `[paths...]` | Files, directories, or globs to build from, relative to the working directory. `-` reads stdin as well. Optional; without them, the configured collections. |

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `-c, --config` | `<path>` | discovered | Path to `manni.config.yaml`. See [Common conventions](#common-conventions). |
| `--no-config` | n/a | off | Ignore any discovered config file. |
| `--collection` | `<name>` | every collection | Read only this configured collection. Repeatable. |
| `--exclude` | `<glob>` | n/a | Glob to exclude. Repeatable. |
| `--as` | `<format>` | by extension | Parse every input as `asciidoc`, `html`, `markdown`, `mdx`, `rst` or `xml`. Required with `-`. |
| `--ext` | `<list>` | `.md,.markdown,.mdx,.html,.htm,.adoc,.asciidoc,.rst,.dita,.ditamap` | Extensions for directory walks and globs, comma-separated. |
| `--allow-empty` | n/a | off | Zero matched files writes an empty graph and exits 0. |
| `-o, --out` | `<path>` | config `out`, else `graph/graph.ttl` | Where to write the Turtle. The directory is created if it does not exist. |

## `graph check`

Validates the built graph against SHACL shapes. This is where the emergent
failures live: they exist only after N documents merge into shared nodes, so no
per-file check can see them. Findings carry the family's
`notice | warning | error` scale, and an `error` exits 1.

```sh
manni graph check [options]
```

```console
$ manni graph check -c test/graph/fixtures/dd/violations.config.yaml
error: https://example.com/dd/concept/alpha skos:broader — skos:broader cycle through https://example.com/dd/concept/alpha, https://example.com/dd/concept/beta (https://example.com/dd/concept/alpha → https://example.com/dd/concept/beta) — a concept cannot be its own ancestor [violations/alpha.md, violations/beta.md, violations/gamma.md]

2 errors, 0 warnings, 0 notices
```

The bundled shapes are **closed**, so a predicate the shapes have not learned
fails here. That is deliberate: a change to what the graph contains is not done
until the shapes say so.

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `-c, --config` | `<path>` | discovered | Path to `manni.config.yaml`. |
| `--no-config` | n/a | off | Ignore any discovered config file. |
| `-g, --graph` | `<path>` | config `out` | The built Turtle file to validate. |
| `--shapes` | `<path>` | config `check.shapes`, else bundled | A shapes `.ttl` file. Repeatable, one path per occurrence, never comma-separated. Given here or in config, these replace the bundled shapes rather than adding to them. Include the bundled file when you mean to extend it. |
| `-f, --format` | `<pretty\|json\|github>` | `pretty` | Output format. `github` writes one workflow annotation per finding. |

## Checking a `graph:` block

There is no `graph validate`. A `graph:` block is frontmatter, and frontmatter is
checked by `manni meta validate` against the page vocabulary. That is the
command every vocabulary in this family is checked with.

The page vocabulary is
[`manni:graph:1.0.0`](/manni/meta/reference/schemas/manni-graph/), a built-in
schema of `manni meta`. Name it for the pages it governs:

```yaml title="manni.config.yaml"
meta:
  overrides:
    - collection: site
      schemas:
        - manni:graph:1.0.0
```

```console
$ manni meta validate
✗ docs/install.md
    /graph  must NOT have additional property 'bogus'  (line 3)  [manni:graph:1.0.0]

1 file checked, 0 passed, 1 failed, 1 error
```

A typo inside the block is a schema error with a line number, because the block
is closed. `manni graph build` reads `x-manni-graph-output` from the set
`manni meta validate` resolves for each page, to decide what a published graph
may carry.

## `graph fill`

Proposes `graph:` frontmatter fields from each page's content and writes the ones
that clear a confidence gate. This is the one verb that reaches a model.

```sh
manni graph fill [paths...] [options]
```

Run `--dry-run` first. The proposals are cached **before** the gate, so
re-running at a different `--confidence` spends no turns. A turn is one
inference call, one page is one turn, and a cached page costs none. A page the
budget stopped at is reported `skipped` with the reason `turn budget`.

With `-`, the page from stdin is filled in memory and printed to stdout, as
`meta fill -` does. The report goes to stderr in either format.

A field already held in an external-metadata manifest counts as filled. Each
key is written where `meta fill` would write it. A key a manifest owns goes to
the page's entry there, and every other key goes to the page. A page that
carries `graph:` while a manifest owns it is that page's error, in the words
`meta validate` uses for the collision.

The graph check vets each proposal against the whole configured corpus. A
corpus page it cannot read is left out, and one warning lists it. A named page
that cannot be read is that page's error.

Every written value is recorded in the page's `meta-provenance`, naming the
model and the fields. See
[Fill the vocabulary](/manni/graph/fill/).

### Arguments

| Argument | Description |
|---|---|
| `[paths...]` | Files, directories, or globs to fill, relative to the working directory. `-` reads stdin as well. Optional; without them, the configured collections. |

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `-c, --config` | `<path>` | discovered | Path to `manni.config.yaml`. |
| `--no-config` | n/a | off | Ignore any discovered config file. |
| `--collection` | `<name>` | every collection | Read only this configured collection. Repeatable. |
| `--exclude` | `<glob>` | n/a | Glob to exclude. Repeatable. |
| `--as` | `<format>` | by extension | Parse every input as `asciidoc`, `html`, `markdown`, `mdx`, `rst` or `xml`. Required with `-`. |
| `--ext` | `<list>` | `.md,.markdown,.mdx,.html,.htm,.adoc,.asciidoc,.rst,.dita,.ditamap` | Extensions for directory walks and globs, comma-separated. |
| `--allow-empty` | n/a | off | Zero matched files is an empty report and exit 0. |
| `-f, --format` | `<pretty\|json>` | `pretty` | Output format. |
| `--dry-run` | n/a | off | Report proposals without writing files. |
| `--force` | n/a | off | Overwrite `graph` fields a human set. Without it, a field already present on the page is left alone. |
| `--no-cache` | n/a | off | Bypass the proposal cache, so every page is asked again. |
| `--no-validate-graph` | n/a | off | Skip the SHACL guardrail that vets each proposal against the derived graph before it is written. |
| `--sections` | n/a | config `fill.sections`, else off | Also propose per-section metadata, not only page-level. |
| `--max-turns` | `<n>` | config `fill.maxTurns`, else unbounded | Stop after this many inference calls. A whole number, at least 1. |
| `--confidence` | `<n>` | config `fill.confidenceThreshold`, else `0.7` | Minimum model confidence, 0 to 1, for a field to be written. Outside that range is a usage error. |
| `--fields` | `<list>` | config `fill.fields`, else every field | Which fields to propose, comma-separated and given once. An unknown name is a usage error naming the allowed set. |
| `--provider` | `<name>` | config `graph.provider`, then `providers.provider`, then `auto` | `auto`, `anthropic`, `openai`, `claude-cli`, or `llama-cpp`. An unknown name is **exit 2**. |
| `--model` | `<model>` | config `graph.model`, else the provider's default | The model within the provider. It needs a named provider, from here or from config, because a model name does not say which provider owns it. |
| `--local` | n/a | off | Run inference on this machine with `llama-cpp`, over `graph.provider` and the family's `providers.provider`. |

## `graph query`

Matches a triple pattern against the built graph. Omit a term and it is a
wildcard, so all three omitted prints the whole graph.

```sh
manni graph query [options]
```

```console
$ manni graph query -c test/graph/fixtures/dd/docs.config.yaml --predicate dcterms:subject
<https://example.com/dd/doc/docs/configuration.md> dcterms:subject <https://example.com/dd/concept/reference>
<https://example.com/dd/doc/docs/getting-started.md> dcterms:subject <https://example.com/dd/concept/onboarding>

2 match(es)
```

The three pattern flags are long-only and named for the triple position each
one fills. `-o` is `--out` on every other verb, and `-s` is the metadata tool's
schema flag. One letter meaning two things across one family costs more than
the letters it saves.

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `--subject` | `<term>` | wildcard | The subject, as a full IRI or a `prefix:local` name. |
| `--predicate` | `<term>` | wildcard | The predicate, as a full IRI or a `prefix:local` name. |
| `--object` | `<term>` | wildcard | The object, as a full IRI, a `prefix:local` name, or a literal value. |
| `-c, --config` | `<path>` | discovered | Path to `manni.config.yaml`. |
| `--no-config` | n/a | off | Ignore any discovered config file. |
| `-g, --graph` | `<path>` | config `out` | The built Turtle file to read. |
| `-f, --format` | `<pretty\|json>` | `pretty` | Output format. |

No match is **exit 0** with `No matches.`, not a finding. A query that asks a
question and gets no answer has not failed.

## `graph stats`

Summarizes the graph. It reports node counts, the most connected documents, orphans,
broken internal links and section references, and per-field metadata coverage.

```sh
manni graph stats [options]
```

```console
$ manni graph stats -c test/graph/fixtures/dd/docs.config.yaml
Triples:    157
Documents:  3
Sections:   8
Concepts:   3
References: 2

Most connected:
  docs/configuration.md (2)
  docs/getting-started.md (2)

Orphan docs (1):
  docs/troubleshooting.md

Broken internal links (1):
  docs/troubleshooting.md -> missing.md
```

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `-c, --config` | `<path>` | discovered | Path to `manni.config.yaml`. |
| `--no-config` | n/a | off | Ignore any discovered config file. |
| `-g, --graph` | `<path>` | config `out` | The built Turtle file to read. |
| `-f, --format` | `<pretty\|json>` | `pretty` | Output format. |
| `--check` | n/a | off | Exit 1 when a broken internal link exists, or when coverage is below its threshold. This is the CI gate. |
| `--top` | `<n>` | every hub | How many most-connected documents to list. A whole number, at least 1. |
| `--coverage-threshold` | `<pct>` | config `stats.coverageThreshold`, else none | Minimum coverage percentage, 0 to 100, applied to every measured field for this run. Outside that range is a usage error. See [Coverage](/manni/graph/govern/coverage/). |

## `graph search`

Ranks graph nodes for a text query. It reads the search index that
`manni graph export search` writes, and adds a vector leg when
`manni graph embed` has written sidecars.

```sh
manni graph search <query> [options]
```

```console
$ manni graph search "installation" -c test/graph/fixtures/dd/docs.config.yaml
0.0164  https://example.com/dd/concept/installation [skos:Concept] — Installation

1 result (lexical)
```

### Arguments

| Argument | Description |
|---|---|
| `<query>` | The text to rank nodes against. Required. |

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `-c, --config` | `<path>` | discovered | Path to `manni.config.yaml`. |
| `--no-config` | n/a | off | Ignore any discovered config file. |
| `-g, --graph` | `<path>` | config `out` | The built Turtle file the index sits beside. |
| `-i, --index` | `<dir>` | beside the graph | Directory holding the indexes and the manifest. |
| `--lang` | `<tag>` | the only localization | Which localization to search, matched in any case. Required when the corpus has more than one. |
| `--limit` | `<n>` | 10 | Maximum results. A whole number, at least 1. |
| `--vectors` | `<path>` | from the manifest | Vector sidecar path. |
| `--mode` | `<mode>` | `hybrid` when vectors exist, else lexical | Which legs to run. An unknown mode is a usage error naming the allowed set. |
| `-f, --format` | `<pretty\|json>` | `pretty` | Output format. |

## `graph traverse`

Walks the graph outward from a node and reports what it reaches, with the full
trace of why each hop was taken. This is the impact question: what depends on
this page, through a hyperlink or through a shared concept.

```sh
manni graph traverse <node> [options]
```

```console
$ manni graph traverse -c test/graph/fixtures/dd/docs.config.yaml \
    https://example.com/dd/doc/docs/getting-started.md --impact
  https://example.com/dd/doc/docs/configuration.md — Configuration
  https://example.com/dd/activity/build
    https://example.com/dd/graph

3 nodes, 5 hops, 0 excluded
```

### Arguments

| Argument | Description |
|---|---|
| `<node>` | Where to start, as a full IRI or a `prefix:local` CURIE. Required. |

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `-c, --config` | `<path>` | discovered | Path to `manni.config.yaml`. |
| `--no-config` | n/a | off | Ignore any discovered config file. |
| `-g, --graph` | `<path>` | config `out` | The built Turtle file to read. |
| `-d, --depth` | `<n>` | 1; 3 under `--impact` | Maximum hops from the node. A whole number, and `0` is allowed: it means the node itself, which is a real answer. |
| `--predicates` | `<list>` | every predicate | Only follow these predicates, comma-separated and given once. A CURIE holds no comma, so one separator is enough. Naming `rdf:type` follows type edges. A predicate no edge uses is exit 2. |
| `--reverse` | n/a | off | Follow inbound edges, to find who points at this node. |
| `--impact` | n/a | off | Transitive inbound reach, to find what a change here affects. |
| `--variant` | `<variant>` | no filter | Scope filter on a product variant IRI, title, or slug. |
| `--software-subject` | `<subject>` | no filter | Scope filter on a software subject. An unknown one is **exit 2**. |
| `--lang` | `<tag>` | no filter | Scope filter on a BCP-47 language tag, matched in any case. |
| `--limit` | `<n>` | unbounded | Stop after this many nodes. A whole number, at least 1. |
| `-f, --format` | `<pretty\|json>` | `pretty` | Output format. |

## `graph export`

Reserializes the built graph into a consumer format. The target is a
positional rather than a `-f`. Every other verb of the family means output
format by `-f`, and one flag cannot mean two things.

```sh
manni graph export <target> [options]
```

```console
$ manni graph export jsonld -c test/graph/fixtures/dd/docs.config.yaml
Wrote 32 nodes to .tmp/dd/graph.jsonld
```

| Target | What it writes |
|---|---|
| `jsonld` | JSON-LD, for a linked-data ingester. |
| `iirds` | A conformant iiRDS package, for a content delivery portal. RDF/XML is written inside it. |
| `search` | The browser search index and its manifest, read client-side by `@hawkeyexl/manni/graph/runtime`. |

An unknown target is **exit 2**, with the allowed set named.

### Arguments

| Argument | Description |
|---|---|
| `<target>` | What to write: `jsonld`, `iirds`, or `search`. Required. |

### Options

| Option | Argument | Default | Description |
|---|---|---|---|
| `-c, --config` | `<path>` | discovered | Path to `manni.config.yaml`. |
| `--no-config` | n/a | off | Ignore any discovered config file. |
| `-g, --graph` | `<path>` | config `out` | The built Turtle file to read. |
| `-o, --out` | `<path>` | the graph path with the target's extension | Where to write. |

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Everything passed. A warning or a notice is still `0`. |
| `1` | Findings. A SHACL `error`, a `stats --check` failure, or a `fill` error. The author's problem. |
| `2` | Operational or usage error. No input files matched, a bad config, an unknown flag value, a missing provider. Not the author's problem. |
