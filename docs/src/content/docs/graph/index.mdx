<Aside type="note" title="In development">
`manni graph` is in development. It is not in the published package.
</Aside>

Your docset is already a graph. Pages link to pages, headings nest, tags repeat across sections, and git knows who wrote what. The graph tool writes all of that down as one file you can query and check. Nothing is inferred from prose.
