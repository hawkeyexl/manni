Some failures exist only in the published site: a page a screen reader cannot
use, or a procedure that no longer works. Checking for them needs the site
built and running, and every framework spells that differently. `manni site`
detects the framework and runs its own commands, so this track works the same
on Starlight, Docusaurus, MkDocs and the rest. This track starts from the
trunk's end state.

## Tell manni how the site builds

On a framework manni detects, this section is empty and `manni site build`
needs no config. The sample has no framework. Its stand-in, `build.mjs`,
renders each page to HTML in `dist/` and serves it. So the sample names its
commands, and the URL the site is served on:

```yaml title="manni.config.yaml"
collections:
  - name: guides
    paths:
      - "docs/**/*.md"
    url: http://127.0.0.1:4322/
    # …externalMetadata, unchanged…

site:
  commands:
    build: node build.mjs
    preview: node build.mjs serve
```

The collection's `url:` says where its pages are published. The next steps read
it, so neither needs a URL of its own.

## Build it

```sh
manni site build
```

```text
manni: Running site.commands.build in ./: node build.mjs
```

`dist/` now holds one HTML page per guide. `manni site preview` builds the same
way, then serves the result until you stop it. The
[site section](/manni/site/) lists the frameworks it detects and their
commands.

## See what is in play

```sh
manni status
```

```text
manni 4.28.0   config manni.config.yaml   collection guides (4 files)

meta       in play       meta: section
cite       not set up    no page carries citations
                         Pin a sentence to its source with manni cite add.
lint       not set up    no lint: section
                         Add a lint: section. manni lint templates lists the templates it can apply.
docevals   in play       4 pages declare evals
term       not set up    no terms in any collection
                         Add a page with type: term to a collection.
strategy   not set up    no strategy records in any collection
                         Add a page with type: journey to a collection.
graph      not set up    no graph: section
                         Run manni graph init to add a starter graph: section.
a11y       not checked   needs a running site and a browser
                         Run manni site preview, then manni a11y check.
test       not checked   runs the pages' shell steps and synthetic users
                         Run manni test procedures or manni test tasks.
tracevals  not checked   judges recorded sessions with a model
                         Run manni tracevals run over sessions, or add tracevals.runtime to judge each turn.
```

`site` has no row, because building is not a check. The `a11y` row names the
next step: preview the site, then check it.
