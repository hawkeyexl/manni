Search, the site's navigation and a docs bot all read a page's frontmatter. A
page that lacks the field one of them needs drops out of it, and nobody hears
about it until a reader looks. A schema turns that into a failing check. It is
also the step every track builds on, because each track's records are metadata
too.

## Name the fields every page needs

Write a JSON Schema for the fields your pages must carry:

```json title="schemas/page.schema.json"
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "Widget docs page",
  "type": "object",
  "properties": {
    "title": { "type": "string", "minLength": 1 },
    "description": { "type": "string", "minLength": 1 },
    "type": { "enum": ["concept", "how-to", "reference"] }
  },
  "required": ["title", "description", "type"]
}
```

Then point the collection at it, under a `meta:` section:

```yaml title="manni.config.yaml"
meta:
  overrides:
    - collection: guides
      defaults: true
      schemas:
        - ./schemas/page.schema.json
```

`defaults: true` keeps the built-in schemas beside yours, so a field a
built-in vocabulary defines is checked too.

## Validate the pages

```sh
manni meta validate
```

```text
Using manni.config.yaml (.)
✓ docs/index.md
✓ docs/reference/cli.md
✓ docs/run-a-job.md
✓ docs/timeouts.md

4 files checked, 4 passed, 0 failed, 0 errors
```

With no paths, `validate` checks the collection. Delete the `description:`
line from `docs/timeouts.md`, and the page fails:

```sh
manni meta validate docs/timeouts.md
```

```text
Using manni.config.yaml (.)
✗ docs/timeouts.md
    (root)  must have required property 'description'  (line 1)  [manni:core:1.0.0]
      manni:core:1.0.0 description: One full non-empty sentence saying what the page is for.
      Guide: https://hawkeyexl.github.io/manni/meta/reference/schemas/manni-core/
    (root)  must have required property 'description'  (line 1)  [./schemas/page.schema.json]
      ./schemas/page.schema.json description

1 file checked, 0 passed, 1 failed, 2 errors
```

The exit code is `1`. Put the line back before you go on. The
[meta section](/manni/meta/set-up/) covers choosing and writing schemas.
