The sample says the CLI waits 30 seconds for a job. That is true today,
because `src/widget.mjs` says so. When someone changes the timeout, the page
still says 30, and no check in the trunk can tell. A **citation** pins the
sentence to the lines it rests on, by a hash of each, and fails when either
side changes. This track starts from the trunk's end state, committed to Git.

## Pin the sentence

Line 11 of `docs/timeouts.md` makes the claim, and line 2 of
`src/widget.mjs` is its source:

```sh
manni cite add docs/timeouts.md:11 src/widget.mjs:2 --id timeout-30s --marker
```

```text
Using manni.config.yaml (.)
docs/timeouts.md: added timeout-30s to docs/timeouts.citations.yaml:3; marker at line 11, claim pinned at line 12 (sha256-53a72cab…; source src/widget.mjs:2 "export const DEFAULT_TIMEOUT_MS = 30000;", sha256-eb291138…, 3e1ccfb)
```

The pin goes into `docs/timeouts.citations.yaml`, beside the page, and a
`cite timeout-30s` marker goes above the sentence. `manni cite check` holds
the pin:

```text
Using manni.config.yaml (.)
✓ docs/index.md
✓ docs/reference/cli.md
✓ docs/run-a-job.md
✓ docs/timeouts.md   docs/timeouts.citations.yaml
    ✓ timeout-30s   marker :11 current   src/widget.mjs:2 current

4 files checked, 4 passed, 0 failed, 0 findings
```

Now change `30000` to `60000` in `src/widget.mjs`, and run `manni cite check`
again:

```text
Using manni.config.yaml (.)
✓ docs/index.md
✓ docs/reference/cli.md
✓ docs/run-a-job.md
✗ docs/timeouts.md   docs/timeouts.citations.yaml
    ✗ timeout-30s   marker :11 current   src/widget.mjs:2 changed since 3e1ccfb, 0 commits
      Check the sentence against the source, then run manni cite update --accept --only timeout-30s.
      manni:cite source-changed: The cited lines are not what they were.
      Guide: https://hawkeyexl.github.io/manni/cite/fix/#source-changed

4 files checked, 3 passed, 1 failed, 1 finding
```

The exit code is `1`, and the finding names the sentence to reread. Put the
value back before you go on. The commit in each transcript is your own, so
yours differs. The [cite section](/manni/cite/get-started/) covers the drift
kinds and their repairs.
