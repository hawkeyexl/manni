A citation's sidecar names its source file in plain text, and the sidecar ships
with the docs. A path into a private repository, or one that names an
unreleased product, says more than the page should. manni can encrypt that
field and still check the pin. Encrypting needs a key, and nobody needs one
before they have a citation to protect, which is why this step follows the
last.

## Set the key

```sh
manni key set
```

```text
manni: manni.config.yaml is not ignored by git: once committed, anyone who can read the repository can decrypt every encrypted value. Prefer MANNI_ENCRYPTION_KEY for a shared repository.
Encryption key written to manni.config.yaml.
```

`key set` generates 256 random bits and writes them to `encryptionKey:` in
`manni.config.yaml`. Read the warning. In a shared repository, keep the key in
the `MANNI_ENCRYPTION_KEY` environment variable and out of the file.
[Where the key lives](/manni/key/#where-the-key-lives) covers both.

## Pin with an encrypted path

Pin the retry claim on line 13 with `--encrypt`:

```sh
manni cite add docs/timeouts.md:13 src/widget.mjs:3 --id retries-3 --marker --encrypt
```

```text
Using manni.config.yaml (.)
docs/timeouts.md: added retries-3 to docs/timeouts.citations.yaml:3; marker at line 13, claim pinned at line 14 (sha256-c2df5c05…; source ~AWr0…:3, hmac-sha256-112bea72…, 7b98544)
```

The sidecar now names the source by its ciphertext, and pins its lines with a
keyed hash:

```yaml title="docs/timeouts.citations.yaml"
docs/timeouts.md:
  citations:
    - id: retries-3
      claim:
        integrity: sha256-c2df5c05ebc86371268f99105b3bebd32523888b0f39cce8170d05e801154450
      source:
        file: ~AWr0z_sMtzhbMW2dPqr51oOQIQyO-H0KT0YZfsmgf3Lk3j-TPeZ1kjimWbXXWbtGIXYa2yTlwvY67Y1iUQ
        lines: 3
        integrity: hmac-sha256-112bea7276d442fec508b46eda955f22b1a55ea3cdcee0ca7b3f2c9a6d8679a6
        commit-sha: 7b98544136920ee8c13780253176220cd5f6a308
```

With the key, `manni cite check` decrypts the path and checks the pin as
before:

```text
Using manni.config.yaml (.)
✓ docs/index.md
✓ docs/reference/cli.md
✓ docs/run-a-job.md
✓ docs/timeouts.md   docs/timeouts.citations.yaml
    ✓ retries-3   marker :13 current   ~AWr0…:3 current

4 files checked, 4 passed, 0 failed, 0 findings
```

Your key is random, so your ciphertext and hashes differ from these.

<Aside type="caution" title="Losing the key">
  A value encrypted under a key decrypts under that key and no other. Rotate
  it with `manni key rotate`, which re-encrypts every value, rather than
  setting a new one over it.
</Aside>
