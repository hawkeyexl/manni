A template checks a page's shape: its sections, and what kind of block each
one holds. Whether the page says what it must is a different question. A
how-to can have every section and still never show the command it is about.
An **eval** on the template asks that question of every page the template
routes. You write the rule once per doctype, not once per page.

`manni status` has listed docevals in play since the trunk. Every built-in
template carries evals of its own, and a model judges those. This step adds one
a regular expression grades, so it needs no model.

## Extend the built-in template

Write a template that extends the built-in how-to and adds one eval:

````yaml title="templates/how-to.yaml"
templates:
  how-to:
    extends: tgdp:how-to:1.6
    types: [how-to]
    evals:
      - id: shows-a-command
        assertion: The page shows the command the reader runs.
        grader: tool:regex
        options:
          pattern: "```sh"
          match: contains
````

Route the how-to pages to it, in place of the `lint: {}` from the step before:

```yaml title="manni.config.yaml"
lint:
  templates:
    - templates/how-to.yaml
```

## Grade the page

```sh
manni docevals run docs/run-a-job.md --deterministic-only
```

```text
docs/run-a-job.md
  skip tgdp-overview-names-the-task  docs/run-a-job.md:4
       judge skipped (--deterministic-only)
  skip tgdp-steps-start-with-a-verb  docs/run-a-job.md:4
       judge skipped (--deterministic-only)
  skip tgdp-one-action-per-step  docs/run-a-job.md:4
       judge skipped (--deterministic-only)
  skip tgdp-shows-the-result  docs/run-a-job.md:4
       judge skipped (--deterministic-only)
  skip tgdp-no-concept-teaching  docs/run-a-job.md:4
       judge skipped (--deterministic-only)
  skip tgdp-one-method  docs/run-a-job.md:4
       judge skipped (--deterministic-only)
  pass shows-a-command  docs/run-a-job.md:4

Suites
  default: 1/1 passed — 100% vs target 100% ok (6 skipped)
```

The page inherits the built-in how-to's six judged evals, and
`--deterministic-only` skips them. `shows-a-command` came from your template,
and the page passes it. [Evals on lint templates](/manni/docevals/evals/named-evals-and-suites/)
covers skipping an inherited eval and naming a shared one.
