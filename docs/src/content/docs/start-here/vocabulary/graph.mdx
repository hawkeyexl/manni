Every check so far reads one file at a time. Some failures live between files:
a page nothing links to, a link to a page that moved, or one concept spelled
two ways. The **graph** reads the whole docset at once. It takes in the term
from the first step and the records from the second, so it comes last in this
track.

## Add the graph section

```sh
manni graph init
```

`graph init` appends a starter `graph:` section to `manni.config.yaml`, with
every setting written out and commented. The defaults write the graph to
`graph/graph.ttl`.

## Build and check it

```sh
manni graph build
manni graph check
```

```text
Wrote …/graph/graph.ttl (8 docs, 192 triples, 1 concepts (1 from the termbase), 3 strategy records)
0 errors, 0 warnings, 0 notices
```

The graph holds eight files, which are the four guides, the term page and
the three records. The `job` term became a concept, and each record a strategy node. `graph check` validates the result against the bundled shapes. The
[graph section](/manni/graph/get-started/) covers querying it and publishing it
with the site.
