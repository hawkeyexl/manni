Agent instructions accumulate. A `SKILL.md` here, a subagent definition there, a `CLAUDE.md` that
has grown past the point anyone rereads it. Nothing checks whether any of it is still being
followed.

**manni tracevals** closes that loop. Give it a session that already happened, and it
deterministically looks up every skill, agent definition, slash command, and project-rules file the
session used. Then it evaluates whether the session **adhered to the instructions in those
artifacts**.

## The 30-second proof

Everything below runs with no API key and no network call.

```bash
npm i -D @hawkeyexl/manni
```

```bash
npx @hawkeyexl/manni tracevals run ./session.jsonl --deterministic-only
```

```
  PASS   fix-bug › used-read
  FAIL   fix-bug › forbidden-tool
         [error] tool Bash was used 1 time(s) but must not be
  SKIP   CLAUDE.md › adheres-to-artifact (implicit)
         ai evals skipped (deterministic-only run)

9 eval(s): 2 pass, 1 fail, 0 error, 1 needs-review, 5 skipped
```

The skill said *"this skill is edit-only"*. The session ran a shell command. Nobody had to notice.

<Aside type="tip" title="One package, every tool">
tracevals ships in `@hawkeyexl/manni` alongside `manni meta`, `manni docevals` and the rest of the
family, and they share one `manni.config.yaml`. If a repo already runs another manni tool, there is
nothing new to install.
</Aside>

## How it works

```
trace (~/.claude/projects/<project>/*.jsonl, or a file you name)
  |
  v
parse ──> resolve artifacts used ──> extract evals ──> plan evals
              (skills, agents,          (metadata.evals
               CLAUDE.md/AGENTS.md)      frontmatter)
  |
  v
deterministic graders ──> ensemble LLM judge (N runs, consensus, zones)
  |
  v
report (pretty / json / markdown) + artifact coverage + history
```

## Requirements

Node.js 24 or newer. No hosted service and no account. The judge provider comes from the family's
`providers:` config, and `--local` runs inference on your own machine.

```bash
npm i -D @hawkeyexl/manni
npx @hawkeyexl/manni tracevals list
```
