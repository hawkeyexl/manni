## Reading these pages

- **Defaults are the resolved values.** Every knob flows through the config file, which fills in
  every default before anything reads it. A CLI flag **overrides** the resolved config instead of
  bypassing it, so the default shown for a flag is the config default it would replace.
- **Unknown configuration keys are errors.** The schema rejects additional properties at every level
  below `tracevals:`, so a typo fails loudly instead of being ignored.
- **Deterministic grader options are validated before grading.** A malformed eval produces an
  `error` outcome naming the offending option, never a silent pass.
- **Connection settings are not on these pages.** Which endpoint, key variable, or command reaches a
  model is declared once for the whole family, in the top-level `providers:` map. It has its own
  [reference](/manni/meta/reference/configuration/#providers), and
  [`tracevals.provider`](/manni/tracevals/reference/configuration/#provider-and-model) only names
  which entry in it to use.
