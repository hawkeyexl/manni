**Scope:** the export surface. How to *use* it is [Build on tracevals](/manni/tracevals/extend/).
Source of truth: `src/tracevals/index.ts`.

```ts
import { tracevals } from "@hawkeyexl/manni";

const trace = tracevals.parseTraceFile("session.jsonl");
```

The tool is a **namespace export** on the package root, beside `docevals`, `cite` and `key`. The
metadata tool's names are the package's flat export. Every sibling tool sits under its own
namespace, so two tools can both have a `loadConfig` without colliding. There is no subpath import
for tracevals.

ESM-only, Node.js 24 or newer, types shipped. **★ marks an intended entry point**. The rest is
exported because the CLI is built from it and it is useful for tests. The starred ones are where to
start.

## Engine

| Export | Notes |
|---|---|
| ★ `runEvals` | Runs the whole pipeline, returns `RunReport`. Needs a `judge` unless `deterministicOnly`. |
| `EngineOptions` | `tracePath`, `projectDir?`, `env?`, `config`, `judge?`, `deterministicOnly?`. |

## Commands

The CLI's verbs, callable directly. Each pairs a runner with a renderer.

| Export | Notes |
|---|---|
| `runRun`, `RunCommandOptions`, `RunCommandResult` | `run`, one trace. `RunCommandOptions.judge` injects a judge. |
| `prepareRun`, `runOne`, `RunContext`, `RunSharedOptions` | The seams a batch reuses. Build the judge, config and plugins once, then evaluate one trace. |
| `runBatch`, `resolveBatchTraces`, `parseNewerThan`, `keepNewerThan`, `BatchCommandOptions`, `BatchCommandResult` | `run` over many traces. `BatchCommandResult.outcomes` pairs each file with its report, errors included. |
| `runCalibrate`, `CalibrateCommandOptions`, `CalibrateCommandResult` | `calibrate`. Accepts the same judge injection through `RunSharedOptions`. |
| `runFill`, `renderFill`, `FillOptions`, `FillReport`, `FillArtifactResult`, `FillRun`, `FillStatus`, `SharpeningNote` | `fill`. `FillOptions.providerInstance` injects a provider. |
| `runCapture`, `renderCapture`, `CaptureCommandOptions`, `CaptureCommandResult` | `capture`. |
| `runList`, `renderList`, `ListOptions`, `ListRun` | `list`. |

The command options spell each flag in camelCase:

| Option | Flag | Notes |
|---|---|---|
| `newerThan` | `--newer-than` | A duration string such as `"7d"`, on `BatchCommandOptions`, `CalibrateCommandOptions` and `ListOptions`. `parseNewerThan` turns one into milliseconds and throws on any other spelling. |
| `allowExecution` | `--allow-execution`, `--no-execution` | The grants to keep, such as `["frontmatter-commands"]`. Absent keeps every grant `execution.allow` holds, and `[]` runs no command eval. It never widens the config. |
| `failOnReview` | `--fail-on-review`, `--no-fail-on-review` | Overrides `config.failOnReview`. Absent defers to the config. |

## Judge

| Export | Notes |
|---|---|
| `makeTraceJudge` | Build the ensemble judge. |
| `makeJudgeProvider`, `providerSpecFor` | Provider construction. `providerSpecFor` resolves identity without constructing, so a fully cached run needs no API key. |
| `renderTrace` | The transcript as the judge sees it, redacted. With a plan, only that artifact's window. |
| `makeRedactor` | The scrubber `renderTrace` applies. Built-in shapes plus any extra sources, which **add to** them. |
| `REDACTION_PATTERNS`, `CUSTOM_PLACEHOLDER` | The built-in shapes with their labels, and the placeholder a configured pattern produces. |
| `compileRedactPatterns` | Compile-check pattern sources up front. Throws `TracevalsError` on one that will not compile. |
| `RedactionPattern`, `Redactor` | |
| `JUDGE_SYSTEM_PROMPT`, `buildUserContent` | The prompts. |
| `PROMPT_VERSION` | Cache-key component. Bump on any prompt change. |
| `cacheKey`, `sha256` | |
| `TraceJudge`, `JudgedEval`, `TraceJudgeOptions`, `RenderOptions` | |
| `MockResponse` | The canned judge response this repository's own tests inject. It is a test seam, not a provider you configure. |

<Aside type="caution" title="`TraceJudge` is the seam, not `makeTraceJudge`">
Anything matching the `TraceJudge` function type works, which is what makes downstream suites
offline-able. You rarely need `makeTraceJudge` unless you want the real ensemble.
</Aside>

## Configuration

| Export | Notes |
|---|---|
| ★ `loadConfig` | Read `manni.config.yaml` from a directory, take its `tracevals` section, validate, and fully populate defaults. |
| `parseConfig` | The same from an object. The argument is the **section**, not the whole file. Pass what sits under `tracevals:`. |
| `DEFAULT_CONFIG_FILENAME` | `"manni.config.yaml"`, the one config file the family shares. |
| `CONFIG_SECTION_KEY` | `"tracevals"`, the top-level key in that file holding this tool's settings. |
| `TracevalsConfig` | |

Downstream code always receives a fully-populated config, so there is no need to re-apply defaults.
Connection settings for inference live elsewhere. They are in the family's top-level `providers:`
map, shared with `manni meta fill` and `manni docevals`. See the
[configuration reference](/manni/tracevals/reference/configuration/).

`TracevalsError` is the operational-failure type, and it extends the family's `ToolError`. The CLI
maps it to exit `2`. Catch it when you want to tell "the tool could not run" apart from "a check
failed".

<Aside title="Stability">
The package is versioned by semantic-release from Conventional Commits. The ★ entry points are the
ones the CLI itself is built on, and the least likely to move. The `fill` internals exist mostly to
serve this repository's own tests.
</Aside>
