# manni lint

<Aside type="note">
  Structure checking is deterministic. There is no model in the loop, and
  there are no network calls except fetching a template you point it at.
</Aside>

manni lint validates the structure of a document against a doctype
template, routed by the page's own `type` frontmatter.
