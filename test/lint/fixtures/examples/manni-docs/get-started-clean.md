# Get started with manni lint

Get manni lint checking your docs in about five minutes.

## Before you start

Install manni: `npm install -g @hawkeyexl/manni`.

## Point it at a doctype

Give a page a `type:` in its frontmatter and manni lint routes it to the
template that matches, with no flag and no config entry.

## Next steps

Read the templates reference to write your own doctype.
