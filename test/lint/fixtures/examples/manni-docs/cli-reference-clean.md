# manni lint

## Global options

| Option | Description |
| --- | --- |
| `-c, --config` | Path to `manni.config.yaml` |

## `manni lint check`

Runs every configured job.

### Arguments

| Argument | Description |
| --- | --- |
| `paths` | Files or directories to check |

### Options

| Option | Description |
| --- | --- |
| `--explain` | Print the resolution chain instead of linting |

## `manni lint structure`

Runs the structure job on its own.
